本專案目前在爬蟲模組的設計上，對於瀏覽器驅動程式（WebDriver）的版本管理機制，尚未達到「自動檢測並下載最新版本」的完整循環。當目標網站或底層瀏覽器發布重大更新時，若 WebDriver 版本與實際運行環境不匹配，系統將會直接拋出 `SessionNotCreatedException` 或類似的執行錯誤，導致爬蟲流程中斷。

為確保系統的穩定性與持續運作能力（Self-healing），必須建立一個專門的「依賴管理層」（Dependency Management Layer）。

以下是針對此問題制定的修改計畫，目的在於使系統能夠自主地更新和初始化所需的瀏覽器驅動程式。

---

### 🛠️ 修改目標：實現 WebDriver 的自動版本檢測與下載機制

**核心概念：** 不應直接依賴本地預設的 `chromedriver.exe` 或 `geckodriver.exe` 路徑，而必須將其升級為一個可運行、可驗證版本的資源。

### 📋 修改計畫步驟 (Modification Plan)

#### Step 1: 建立版本檢測與下載模組 (`WebDriverManager`)

*   **功能描述：** 新增一個獨立的 Python Class 或 Module，專門負責管理 WebDriver 的生命週期。
*   **實作細節：**
    1.  **目標識別 (Target Identification)：** 定義當前爬蟲所依賴的瀏覽器類型（例如：Chrome, Firefox）及其版本範圍。
    2.  **版本查詢機制 (Version Query)：** 該模組必須能夠透過 API 或官方文件，獲取目前穩定版瀏覽器的最新建議驅動程式版本號。
    3.  **本地比對與檢查 (Local Check)：** 比較「所需版本」與「本地已存在版本」。若不匹配或不存在，則觸發下載流程。

#### Step 2: 實作自動下載與路徑管理

*   **功能描述：** 當檢測到版本落後時，執行安全、可靠的下載操作並將驅動程式放置於專案可讀寫的緩存目錄（Cache Directory）。
*   **技術考量 (Technical Consideration)：**
    1.  **下載來源：** 應使用官方推薦或業界標準的 WebDriver 管理庫（例如 `webdriver-manager` 或類似機制）來處理下載，避免手動爬取驅動程式連結帶來的風險。
    2.  **路徑管理：** 下載後的驅動程式必須被放置在專案根目錄下的特定資料夾 (e.g., `./cache/drivers/`)，並確保所有爬蟲初始化時都指向此絕對路徑。

#### Step 3: 重構爬蟲啟動流程 (Integration Point)

*   **修改點：** 所有執行 `webdriver.Chrome()` 或 `webdriver.Firefox()` 的地方，必須將其初始化邏輯包裹在一個新的「環境準備函數」中。
*   **流程順序 (Execution Flow)：**
    1.  `[Start]` $\rightarrow$ 呼叫 `WebDriverManager.initialize_driver(browser_type)`。
    2.  `WebDriverManager` 執行版本檢測、下載（若需要）。
    3.  `WebDriverManager` 返回一個已驗證的 WebDriver Session Object。
    4.  爬蟲核心邏輯開始運行，使用該穩定的 Session Object。

### ✅ 專案歷史踩坑防禦要點提醒 (Mandatory Safety Checks)

在實作此自動化依賴管理模組時，請務必注意以下開發規範：

1.  **【Unicode 防禦】:** 若 `WebDriverManager` 需要讀取本地的配置或環境變數檔案（如 `.env`），所有 I/O 操作必須明確指定編碼處理，例如使用 `open(file_path, encoding='utf-8', errors='ignore')`。
2.  **【零破壞原則】:** 此依賴管理模組應作為一個獨立的服務層 (Service Layer) 運行，不應修改或干擾現有的 K 線圖繪製邏輯 (`ApexCharts`) 或任何計算金融指標的核心業務函數。它只負責提供穩定的執行環境。
3.  **【JSON 序列化保護】:** 若在爬蟲過程中需要將抓取的結構化數據（如日期、浮點數）回傳給後端 API，請務必使用標準化的資料轉換器 (Data Transformer)，確保所有 `datetime` 和 `decimal.Decimal` 類型都被格式化為 ISO 8601 字串或 Python 標準的 `float`/`str`。
