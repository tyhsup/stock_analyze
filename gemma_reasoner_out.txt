這是一個典型的前端響應式佈局（Responsive Layout）優化需求。由於您要求的是「副圖完全等高等寬」，這代表我們需要一個能夠精確監測父容器尺寸變化，並將尺寸均分給所有子元素的機制。

使用 `ResizeObserver` 是目前最標準且最精準的解決方案，它優於傳統的 `window.onresize` 事件，因為它能監測特定元素（而非整個視窗）的尺寸變化。

以下提供完整的架構分析與實作建議。

---

### 📐 架構分析與實作建議

#### 1. 核心技術選用：`ResizeObserver`
*   **優點：** 它只在目標元素尺寸改變時觸發回調函數，性能優於監測整個 `window` 的事件。
*   **應用場景：** 我們將監測包含所有副圖的父容器（假設為 `sub-charts-container`）。

#### 2. HTML/CSS 結構調整 (CSS First)
為了確保佈局的基礎穩定性，我們必須使用 CSS Grid 或 Flexbox 來定義子元素的排列方式。

**CSS 建議：**

```css
/* 假設這是包含所有副圖的父容器 */
.sub-charts-container {
    display: flex; /* 使用 Flexbox 進行水平排列 */
    flex-wrap: wrap; /* 允許在空間不足時換行 */
    gap: 15px; /* 設定圖表間的間距 */
    /* 確保這個容器的寬度是可變動的 */
    width: 100%; 
}

/* 每個副圖的包裹元素 */
.sub-chart-wrapper {
    /* 初始設定：讓它在 Flex 容器中佔據空間 */
    /* 實際寬度將由 JavaScript 動態覆蓋 */
    flex-grow: 1; 
    /* 確保高度一致性，如果圖表本身高度不一致，可考慮設定一個最小高度 */
    min-height: 300px; 
    /* 這是圖表內容的容器，必須保持獨立 */
    box-sizing: border-box;
}
```

#### 3. JavaScript 邏輯實作 (JS Logic)
我們需要一個初始化函數，用來執行尺寸計算和監聽器綁定。

**JavaScript 建議：**

```javascript
/**
 * @function initializeSubChartResizing
 * @description 根據父容器的寬度，計算並強制將所有子圖表包裹元素設置為等寬。
 * @param {string} containerSelector - 包含所有副圖的父容器選擇器 (e.g., '.sub-charts-container')
 */
function initializeSubChartResizing(containerSelector) {
    const container = document.querySelector(containerSelector);
    if (!container) {
        console.error("Error: Sub-charts container not found.");
        return;
    }

    const chartWrappers = container.querySelectorAll('.sub-chart-wrapper');
    const numCharts = chartWrappers.length;

    if (numCharts === 0) {
        console.warn("No sub-chart wrappers found.");
        return;
    }

    /**
     * 核心計算與應用函數
     * @param {number} containerWidth - 父容器的當前寬度
     */
    const applyEqualWidth = (containerWidth) => {
        // 計算每個圖表應佔用的理想寬度
        // 考慮到 gap (間距) 的影響，我們需要減去 (numCharts - 1) * gap
        const gapWidth = 15; // 必須與 CSS 中的 gap 值一致
        const totalGapSpace = (numCharts - 1) * gapWidth;
        
        // 總可用寬度 = 容器寬度 - 所有間距
        const usableWidth = containerWidth - totalGapSpace;
        
        // 每個圖表應佔用的寬度
        const calculatedWidth = usableWidth / numCharts;

        // 迭代並強制設置每個子圖表的寬度
        chartWrappers.forEach((wrapper, index) => {
            // 設置寬度，並確保它不會超過計算值
            wrapper.style.width = `${calculatedWidth}px`;
            // 由於我們使用了 flex-grow: 1，這裡的 style.width 覆蓋了 flex 預設行為
        });
    };

    // 1. 執行一次初始化計算 (確保頁面載入時尺寸正確)
    // 使用 getBoundingClientRect() 獲取元素的實際尺寸
    const initialWidth = container.getBoundingClientRect().width;
    applyEqualWidth(initialWidth);

    // 2. 綁定 ResizeObserver
    const resizeObserver = new ResizeObserver(entries => {
        for (let entry of entries) {
            if (entry.target === container) {
                // 當父容器尺寸改變時，重新計算並應用寬度
                const newWidth = entry.contentRect.width;
                applyEqualWidth(newWidth);
                console.log(`[Resizer] Container resized to ${newWidth.toFixed(2)}px. Charts adjusted.`);
            }
        }
    });

    // 監測父容器的尺寸變化
    resizeObserver.observe(container);
}

// 確保 DOM 完全載入後執行此函數
document.addEventListener('DOMContentLoaded', () => {
    // 假設您的副圖容器的 class 名為 'sub-charts-container'
    initializeSubChartResizing('.sub-charts-container');
});
```
